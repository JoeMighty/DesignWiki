# G

## Golden Ratio
**Category:** Layout · **Difficulty:** Intermediate

An irrational mathematical ratio (~1.618:1), often written as **φ (phi)**. Forms found in nature and architecture approximate this ratio, and it has been used to create proportional layouts, type scales, and logo designs.

**Related:** [Rule of Thirds](./r), [Grid](./g), [Proportion](./p)

---

## Grid
**Category:** Layout · **Difficulty:** Beginner

An invisible structural framework of columns, rows, and gutters used to organise content consistently. Grids create alignment and rhythm, making complex layouts manageable.

> **Types:** manuscript grid, column grid, modular grid, hierarchical grid.

**Related:** [Column](./c), [Gutter](./g), [Alignment](./a), [Baseline Grid](./b)

---

## Gutter
**Category:** Layout · **Difficulty:** Beginner

The space between columns in a grid layout. In printed books, the gutter also refers to the inner margin where pages are bound together.

**Related:** [Grid](./g), [Column](./c), [Margin](./m)

---

## Glyph
**Category:** Typography · **Difficulty:** Intermediate

A single visual representation of a character in a font — including letters, numbers, punctuation, ligatures, and special symbols. A font file may contain thousands of glyphs.

**Related:** [Ligature](./l), [Character](./c), [Typeface](./t)

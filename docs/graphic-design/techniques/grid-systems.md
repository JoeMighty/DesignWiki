# Grid Systems

**Difficulty:** Intermediate
**Discipline:** Graphic Design — Techniques

## What Is a Grid System?

A grid system is a structured framework of columns, rows, gutters, and margins that provides a scaffold for placing design elements consistently and intentionally. Grids bring **order without rigidity** — they define where things *can* go, not where they *must* go.

## Types of Grids

### Manuscript Grid
A single-column layout. Used for long-form text: books, essays, long-reads. Simple, focused.

### Column Grid
Multiple vertical columns (typically 3, 4, 6, or 12). Content can span single or multiple columns. The most common layout grid for editorial, web, and app design.

### Modular Grid
Columns *and* rows create a matrix of cells. Used for complex publications, calendars, and UI components. Offers maximum flexibility.

### Hierarchical Grid
A free-form, content-driven structure — used where content shapes the grid rather than the grid shaping content. Common in web design and editorial features.

## Setting Up a Column Grid

1. **Define your page/canvas size**
2. **Set margins** — typically 10–15% of page width
3. **Choose column count** — 12 columns is the most versatile (divisible by 2, 3, 4, 6)
4. **Set the gutter** — space between columns (5–20px for digital, 4–8mm for print)
5. **Add a baseline grid** — align to your body text leading

## Column Grid Formula

```
Content width = Page width − (left margin + right margin)
Column width = (Content width − (gutters × (columns − 1))) ÷ columns
```

## The 12-Column Grid

A 12-column grid allows for:
- **Full width**: 12 columns
- **Half-width**: 6 columns each
- **Thirds**: 4 columns each
- **Quarters**: 3 columns each
- **Sidebar layout**: 3 + 9 columns

## Tips

- Break the grid **intentionally** — a rule is only powerful when it's broken with purpose
- The grid is invisible to the viewer; the consistency it creates is what they feel
- Start with more columns than you think you need — you can always span more

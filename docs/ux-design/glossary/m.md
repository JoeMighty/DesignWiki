# M

## Mental Model
**Category:** Cognitive Psychology · **Difficulty:** Intermediate

The internal representation a user has of how a system works — built from past experience with similar products. Good UX aligns the **system model** (how it actually works) with the user's mental model (how they expect it to work).

**Related:** [Affordance](./a), [Cognitive Load](./c), [Jakob's Law](./j)

## Minimum Viable Product (MVP)
**Category:** Design Process · **Difficulty:** Beginner

The simplest version of a product with just enough features to be usable by early adopters and generate validated learning. In UX terms, an MVP tests core hypotheses about user needs with minimal development investment.

**Related:** [Prototype](./p), [Usability Testing](./u), [Lean UX](./l)

# W

## Wireframe
**Category:** Design Process · **Difficulty:** Beginner

A low-to-mid fidelity layout blueprint showing the structure, hierarchy, and rough content placement of a screen — without visual styling applied. Wireframes communicate layout intent and allow rapid iteration before committing to visual design.

> Wireframes answer "what goes where?" — not "what does it look like?"

**Related:** [Prototype](./p), [Fidelity](./f), [Information Architecture](./i)

## WCAG (Web Content Accessibility Guidelines)
**Category:** Accessibility · **Difficulty:** Intermediate

The international standard for web accessibility published by the W3C. WCAG 2.1 defines success criteria across four principles: **Perceivable, Operable, Understandable, Navigable (POUR)**.

| Level | Requirement |
|-------|-------------|
| A | Minimum — must pass |
| AA | Standard — expected by most organisations and law |
| AAA | Enhanced — aspirational |

**Related:** [Accessibility](./a), [Contrast](../graphic-design/glossary/c)

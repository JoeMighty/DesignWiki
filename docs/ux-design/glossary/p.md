# P

## Persona
**Category:** User Research · **Difficulty:** Beginner

A fictional but research-based representation of a key user type. Personas synthesise qualitative research data — behaviours, goals, frustrations, context — into a memorable, human character that keeps the team focused on real user needs.

> Personas are a design tool, not a marketing demographic. Base them on research, not assumptions.

**Related:** [User Research](./u), [Empathy Map](./e), [Job-to-be-Done](./j)

---

## Progressive Disclosure
**Category:** Interaction Design · **Difficulty:** Intermediate

Presenting only the information and controls the user needs at each stage of an interaction — revealing more complexity only when the user needs or requests it. Reduces cognitive load without reducing functionality.

> Example: a "Basic" and "Advanced" settings split; inline help text that only appears on field focus.

**Related:** [Cognitive Load](./c), [Information Architecture](./i), [Affordance](./a)

---

## Prototype
**Category:** Design Process · **Difficulty:** Beginner

A testable simulation of a design, ranging from paper sketches to fully interactive digital models. The purpose of a prototype is to learn — not to build a final product.

**Related:** [Fidelity](./f), [Usability Testing](./u), [Wireframe](./w)
